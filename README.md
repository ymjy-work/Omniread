# Omniread

**故事未完，随时重逢。**

那些读到一半的故事，那些念念不忘的角色，都值得再次相遇。
Omniread 陪你找回剧情、解开疑问，让每一次重逢都自然发生。

## 这是什么

一个能「边读边问」的小说阅读器：阅读页放着原文，旁边随时可以提问。
回答由 AI 生成，**逐处标注它依据的章节**，点角标就跳回那一章。

## 能做什么

- **把阅读与理解，放在同一个空间** —— 小说、章节导航与 AI 助手并行工作。阅读时随时提问，无需切换应用或丢失上下文。
- **忘记了前面的剧情？随时接着读** —— 快速梳理人物关系、关键事件与伏笔，让读过的内容重新建立联系，不必从头翻找。
- **想知道多少，由你决定** —— 无剧透档位严格限定在当前阅读进度；完整剧透档位允许深入讨论后续发展、隐藏伏笔与人物结局。
- **从一个喜欢的角色，认识整个故事** —— 探索角色经历、关系变化与关键章节。即使暂时没有时间读完整本书，也能从感兴趣的地方开始。
- **答不了就说答不了** —— 材料不足时明确拒答，不猜、不编；出处逐句可核。
- **读有边界，问无边界** —— 阅读只开放第 1 卷，问答覆盖整本书。

## 演示内容

《不时轻声地以俄语遮羞的邻座艾莉同学》（日语轻小说，15 卷 / 193 章）。

- **阅读页**开放第 1 卷共 11 章（含插图）
- **问答**覆盖全书——这是刻意的取舍，不是技术限制：阅读范围收窄是为了控制原文的展示量，
  问答则要完整展示检索与回答的能力
- 账户由开发者发放，**不开放注册**
