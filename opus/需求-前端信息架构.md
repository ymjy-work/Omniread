# 前端信息架构需求

日期：2026-11-20

## 1. 总体布局（类 Codex 三栏）

登录后的功能页面统一挂在一个应用壳内：

- **左栏（常驻侧边栏）**：主导航 tab，只有两项——「书库」「阅读」。左下角放用户头像。
- **中栏**：当前 tab 的功能内容。
- **右栏（可折叠）**：阅读对话 chat 面板。

公开页不进壳：`/`（落地）、`/plans`（套餐）、`/login` 独立成页。

## 2. 右栏 chat

- chat 上下文 = 当前打开的书 + 阅读进度；必须沿用现有 rag 契约（`level` 过去/全书、
  引用展示、越界拒答），不得做成与书无关的通用聊天。
- 未打开书时（如书库页）右栏收起或提示先选书。
- 模型选择保持现设计：输入框右下角「官方 / 自己」切换 + 「拉取」。

## 3. 左下角头像（设置入口）

- 侧边栏左下角头像 → 弹层（popover 或抽屉），包含三块：
  1. 用户信息：用户名、展示名、当前档位、剩余积分、余额、到期时间。
  2. 网页设置：主题、正文字号。
  3. 额度情况：积分/余额摘要（与用户信息块可合并呈现）。
- 退出登录入口随头像弹层走。
- 独立 `/settings` 页面取消；BYOK 配置整体归入阅读页 chat 输入区右下角的「自己」面板：
  provider 选择、Key 保存/掩码/删除、模型「拉取」都在该面板内完成，不再单设入口。
- 头像弹层不放套餐购买，也不放管理入口。

## 4. 套餐页

- `/plans` 公开页保留（宣传 + 登录态购买/续费）。
- 功能页面（侧边栏、头像弹层、书库顶栏）不再出现套餐入口与购买逻辑。

## 5. 管理区

- 仅通过 `/admin` 路径进入，独立登录页 `/admin/login`、独立布局。
- 不出现在用户功能页任何导航中。

## 6. 路由表

| 路径 | 进壳 | 说明 |
| --- | --- | --- |
| `/` | 否 | 公开落地页 |
| `/plans` | 否 | 公开套餐页（登录态可购买） |
| `/login` | 否 | 登录/注册 |
| `/library` | 是 | 书库 tab |
| `/books/**` | 是 | 阅读 tab（中栏正文 + 右栏 chat） |
| `/admin`、`/admin/login` | 否 | 管理区，独立 |

`/settings` 路由删除；未登录守卫、`redirect` 回跳、双 token 分离逻辑不变。

## 7. 移动端

- 三栏降级：左栏收为顶部/底部导航或抽屉，chat 变抽屉或切换视图；不允许横向滚动。

## 8. 视觉

- 布局范式参照 Codex，配色与组件语言沿用「纸页与朱批」（见 `opus/设计-页面方向.md`）。
