# 前端信息架构需求

日期：2026-11-19

## 1. 登录

- 不做宣传/landing 页，直接登录表单。
- 未登录访问任何页面都跳登录；登录后回到原目标页。

## 2. 用户区与管理员区分离

- 用户区：书库、阅读、设置、套餐。
- 管理员区：独立 `/admin` 页面与布局，仅 `role=admin` 可进。
- 管理员只做用户管理：建号、用户列表、发放余额；不混入阅读、套餐、BYOK 等用户功能。
- 用户设置与套餐页不得调用管理员接口；普通用户看不到管理入口。

## 3. 套餐页（独立）

- 新增 `/plan` 页面，展示 free/plus/pro/ultra 与购买/续费。
- 设置页不再放套餐购买卡片，只展示当前档位、剩余积分、余额、到期时间，并提供进入套餐页的入口。

## 4. 设置页

设置页只保留：

1. 网页设置：主题、正文字号。
2. 用户信息：用户名、展示名、当前档位、剩余积分、余额、到期时间。
3. 模型配置：BYOK provider + Key 管理，以及默认模型偏好。

## 5. 对话模型选择

- 模型选择移到输入框右下角，不再占据顶部大块区域。
- 在输入框右下角切换「官方 / 自己」：
  - 官方：展示平台模型选择；free 档只有 auto。
  - 自己：选择 provider，模型 ID 通过「拉取」按钮从后端获取，不再要求用户手填。
- 拉取失败、无 Key、积分不足都要就地提示。

## 6. 后端配套

- 新增 `GET /api/me/api-keys/{provider}/models`：用已保存的 BYOK Key 调提供商的 OpenAI 兼容 `/models`，返回模型 ID 列表；不记录明文 Key。
- 平台模型继续使用 `GET /api/models?mode=platform&provider=bailian`。
